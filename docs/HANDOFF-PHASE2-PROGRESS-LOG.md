- what is left / problems / decisions for the owner: the imputation mask is used for two things, not just reporting. Besides counting observed values per group, cells flagged as imputed enter the weighted moderated fit with weight 0.05 (`DiffOptions.imputedWeight`, documented in `prep.ts`). Without this, a single left-censored MinProb filler can dominate a feature's residual variance and hide a real effect: with the mask ignored the planted test recovered only 20/40 at FDR 0.05. With the weight it recovers the required ≥ 25/40 while keeping ≤ 5 false positives. `normalise` implements only none/median/quantile; VSN is neither implemented nor offered. Quantile normalisation with ties keeps equal values equal by averaging the reference quantiles over the tied ranks, so sorted vectors are identical across samples only when there are no ties, which is how the handoff phrases the invariant.

- what is left / problems / decisions for the owner:
  1. Two demo symbols in the handoff do not exist in database 2026-08-07.1: `tetA` is published as `tet(A)` and `aac(6')-Ib` only appears as the allele field of `aac(6')-Ib-cr` (and the `-cr4/5/6` records), so those two symbols are used. Both are present as exact symbols, are detected by the screen and are annotated with TETRACYCLINE and AMINOGLYCOSIDE/QUINOLONE respectively.
  2. `blaTEM-1` is present as a symbol but **cannot** be found by the mandated algorithm, so the fifth demo gene is `blaOXA-1` (oxacillin-hydrolyzing class D beta-lactamase, BETA-LACTAM). Proof: of its 847 forward 15-mers, 0 survive the "drop k-mers occurring in more than 50 references" rule — every blaTEM 15-mer is shared by more than 50 blaTEM alleles, so the gene has no seed at all and screening a contig carrying the exact blaTEM-1 sequence returns zero hits. `blaKPC-2`, `blaCTX-M-15` and `blaNDM-1` behave the same way (0.00–0.02 of their k-mers survive). This is a real limitation of a 15-mer seed screen, not a bug in the implementation; the Gene library tab states it in plain words and the studio's `limits` field carries it too. Raising the 50-reference threshold was not done because the handoff fixes it and because the dropped runs are exactly the ones that make the index too big for a browser.
  3. Window clipping (needed to meet the < 60 s requirement): the first implementation used the handoff's window `[queryStart − 50, queryStart + refLength + 50]` literally, i.e. a full reference-length window starting at the first seed. Screening E. coli K-12 then took 83.5 s because 449 candidate buckets planned 4,589 M DP cells, 179 of them from noise buckets holding exactly the minimum 6 votes. The window end is now additionally clipped to the seed-supported span (`min(queryStart + refLength + 50, lastSeedPos + k + 50)`). A genuine full-length locus still gets its whole reference-length window, because its seeds span it; a noise bucket only pays for the few hundred bases it actually seeded. The result is 17–24 s on the same machine with the identical 10-hit output, and every other test value is unchanged.
  4. `align()` throws above 25 M matrix cells, which the 23,727 bp reference records would hit against a multi-kb window. Each candidate therefore trims the reference to `floor(24 M / window length)` bases when the product would exceed 24 M cells. Coverage is then computed against the full reference length, so long operons are reported conservatively (they fail the 60 % coverage threshold rather than crash) and nothing throws.
  5. One expected value was changed after being proven wrong, not weakened: the truncated-gene test asserted identity 1.0 for the half-length `sul1`. The reported hit is the 828 bp `sul1` homologue, not the 840 bp record that was cut in half, because both align the same 420 columns and identity·coverage prefers the shorter reference (0.506 vs 0.500) — which is exactly the overlap rule the handoff specifies. That homologue differs from the inserted sequence at one base inside the half, so identity is 419/420 = 0.9976190. The test now asserts the two coverage brackets the handoff requires, `refLength === 828` and identity > 0.99. The handoff's identity-1.0 requirement applies to the three exact genes in the five-gene contig, where it holds at 1.000000.
  6. No test was relaxed for timing: the 60 s and 25-hit limits are the handoff's numbers and both hold. The index build is cached in the worker, so only the first screen of a session pays the 3–4 s.
