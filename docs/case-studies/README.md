# Case studies on public data

Three analyses of published datasets, done the way a user would do them in the Workbench. Every number below is
regenerated by a script, and every figure is captured from the Workbench itself.

```bash
bash benchmarks/fetch.sh            # public data into benchmarks/.cache (checksummed)
npm run case-studies                # numbers → docs/case-studies/results/*.json
npm run build && npx playwright test -c docs/case-studies/playwright.config.ts   # figures → docs/case-studies/figures/
```

Runtimes are for one CPU thread under Node (the same code the browser runs) on a 16-core Linux workstation, unless
stated otherwise.

## A · Glucocorticoid response of airway smooth muscle (bulk RNA-seq, paired design)

**Question.** Which genes and pathways does dexamethasone change in human airway smooth-muscle cells?

**Data.** Himes BE et al. (2014) *PLoS ONE* 9:e99625, GEO GSE52778: four primary cell lines, each untreated and
treated with 1 µM dexamethasone for 18 h (8 samples). Gene counts from the Bioconductor `airway` 1.32.0 data package
(LGPL); `benchmarks/deseq2/airway_counts.tsv.gz`.

**Steps in Expression Studio.** Load the count matrix and the sample sheet (`sample, cell, dex`). Design: both
variables in the model, giving `~ cell + dex` (the cell line pairs each treated sample with its own control). Question:
compare two levels of `dex`, `trt` against `untrt`. Thresholds: CPM ≥ 1 in ≥ 2 samples, FDR ≤ 0.05, voom weights on.
Enrichment tab: Reactome, preranked GSEA on the moderated t (20,000 permutations), and ORA of genes with FDR ≤ 0.05
and |log2FC| ≥ 1.

**Results** (`results/airway.json`). 15,041 genes tested; 5,003 at FDR ≤ 0.05 (2,545 up, 2,458 down); 503 up and
454 down by at least two-fold. The classic glucocorticoid-response genes are all strongly induced:

| Gene | log2FC (Workbench) | log2FC (DESeq2) | FDR | Rank of 15,041 |
|---|---|---|---|---|
| DUSP1 | 2.93 | 2.95 | 3.2e-6 | 2 |
| ZBTB16 | 7.14 | 7.35 | 6.5e-6 | 26 |
| PER1 | 3.16 | 3.19 | 5.9e-6 | 24 |
| KLF15 | 4.50 | 4.46 | 7.7e-6 | 31 |
| FKBP5 | 3.98 | 4.05 | 1.6e-5 | 73 |
| TSC22D3 (GILZ) | 3.22 | 3.19 | 2.1e-5 | 102 |
| CRISPLD2 | 2.62 | 2.63 | 2.4e-5 | 119 |

CRISPLD2 is the gene Himes et al. highlight as a novel glucocorticoid-responsive gene in this dataset; DUSP1, KLF15,
PER1, TSC22D3 and FKBP5 are textbook glucocorticoid-receptor targets. Fold changes agree with DESeq2 to within 0.2.

Pathways: ORA of the up-regulated genes gives *Response to metal ions* (the metallothioneins, FDR 0.010),
*Muscle contraction*, *Degradation of the extracellular matrix*, *Laminin interactions*, *IGFBP regulation* and
*FOXO-mediated transcription* (FDR 0.02); the down-regulated genes are enriched for GPCR ligand binding and GPCR
signalling (FDR 3e-5). Preranked GSEA puts *Smooth muscle contraction*, *Muscle contraction*, *PDGFRA signalling* and
*Leptin signalling* among positively enriched sets and *tRNA aminoacylation* among negatively enriched ones (FDR 0.019).

Figures: `figures/airway_volcano.png`, `figures/airway_ma.png`, `figures/airway_gsea_reactome.png`.

**Runtime.** Differential expression 1.1 s; GSEA with 20,000 permutations 9.6 s.

**Limitations.** GSEA p-values come from permutations, so the smallest attainable FDR is set by the number of
permutations (many sets tie at FDR 0.019 here); with 2,000 permutations no set passes FDR 0.1. Fewer genes would be
called by DESeq2 (3,909), as the benchmark shows; the ranking of the top genes is the same.

## B · Cell types in peripheral blood (single-cell RNA-seq)

**Question.** Which immune cell types are present in 2,700 peripheral blood mononuclear cells, and can the
Workbench label them automatically?

**Data.** 10x Genomics PBMC3k (Chromium v1, healthy donor; CC BY 4.0), the standard Seurat and Scanpy tutorial
dataset. Published annotation for comparison: Scanpy's processed PBMC3k (8 cell types, 2,638 cells).

**Steps in Single-Cell Studio.** Choose the three 10x files (matrix.mtx, genes.tsv, barcodes.tsv); default parameters
(≥ 200 genes and ≤ 20 % mitochondrial reads per cell, 2,000 highly variable genes, 20 PCs, 15 neighbours, resolution
0.8); Run pipeline.

**Results** (`results/pbmc3k.json`). 2,699 cells kept, 10 clusters. The built-in marker panel labels the clusters as
T cells (2 clusters), CD8 T cells, NK cells, B cells, CD14+ and FCGR3A+ monocytes, dendritic cells and platelets, with
the expected top markers (for example LYZ and S100A9 for CD14+ monocytes, CD79A for B cells, NKG7, GZMB and PRF1 for
NK cells, PPBP for platelets). Against the published annotation, **92.5 % of cells get the matching label**:

| Published type | Cells | Workbench label | Correct |
|---|---|---|---|
| CD4 T cells | 1,144 | T cells | 95.8 % |
| B cells | 342 | B cells | 99.4 % |
| CD14+ monocytes | 480 | CD14+ monocytes | 84.0 % |
| CD8 T cells | 316 | CD8 T cells | 84.2 % |
| NK cells | 154 | NK cells | 89.0 % |
| FCGR3A+ monocytes | 150 | FCGR3A+ monocytes | 100 % |
| Dendritic cells | 37 | Dendritic cells | 89.2 % |
| Megakaryocytes | 15 | Platelets | 93.3 % |

Figures: `figures/pbmc3k_umap.png`, `figures/pbmc3k_annotation.png`.

**Runtime.** 10.2 s for the whole pipeline including UMAP on all 2,699 cells.

**Limitations.** The marker panel is a short, fixed list (8 types); it does not separate naive from memory CD4 T cells
and labels one small cluster of 8 cells, which has no clear markers, as CD8 T cells. Cluster-level ARI against the
published labels is 0.61 because the clustering splits some published types (the same as Scanpy at this resolution,
see the benchmark).

## C · Mutations in an evolved line of the E. coli long-term evolution experiment (variant calling)

**Question.** Which mutations separate an evolved population of the Lenski long-term evolution experiment (LTEE)
from its ancestor?

**Data.** Reads: SRA SRR2584863 (Illumina HiSeq, 150 bp; an evolved LTEE line, Tenaillon et al. 2016 *Nature*
536:165), first 800,000 read-1 sequences (25× coverage, 280 MB). Reference: the ancestor, *E. coli* B str. REL606,
NCBI NC_012967.1 (4.63 Mb), with its RefSeq gene annotation.

**Steps in Genome Studio.** Mapping & variants: load the REL606 FASTA and the FASTQ; minimap2 preset `sr`; caller
bcftools, ploidy haploid; Map & call. Annotation by gene is done in the script from the RefSeq GFF3.

**Results** (`results/ecoli.json`, `results/ecoli_workbench.vcf`). 99.6 % of reads map; 23 variants (17 SNVs, 6 indels),
22 of them with QUAL ≥ 100, 18 inside genes. **All 23 are also called by native minimap2 2.28 + bcftools 1.21**; the
three calls only native bcftools makes have QUAL 6, 22 and 26. The mutated genes include *topA*, *fis*, *pykF*,
*nadR*, *iclR*, *malT*, *mrdB* and *hslU*. Several of these are known targets of repeated, parallel mutation in the
LTEE: *topA* and *fis* (DNA supercoiling; Crozat et al. 2005 *Genetics* 169:523) and *pykF*, *nadR* and *iclR*
(Tenaillon et al. 2016), so the result is consistent with what is known about this experiment. (Authors: check these
gene-level citations against the papers before submission.)

Figures: `figures/ecoli_coverage.png`, `figures/ecoli_variants.png`.

**Runtime.** 436 s in Node on one thread (minimap2 takes most of it), against 25 s for the native tools; in the browser
see `results/ecoli_browser_runtime.json`. This is the price of running the real tools as WebAssembly without
installing anything.

**Limitations.** Read 1 only (the Workbench maps single-end reads); a subsample of the run, so low-frequency mutations
in the population are not resolved; the browser's bcftools is version 1.10, whose QUAL values differ from 1.21 even
though the calls and genotypes are the same (see benchmarks/RESULTS.md). Gene effects (synonymous, missense) are not
predicted.
